# migros-mcp 🇹🇷

سرور MCP غیررسمی و **فقط‌خواندنی** برای **میگروس** ترکیه (migros.com.tr)، بزرگ‌ترین زنجیره‌ی سوپرمارکتی ترکیه — جست‌وجوی زنده‌ی محصولات، قیمت‌ها، تخفیف‌های Money، دسته‌بندی‌ها و آمار قیمت.

> بخشی از «کارخانه‌ی MCP ترکیه». هیچ وابستگی به میگروس ندارد. این میگروس **ترکیه** است — نه میگروس سوئیس که بسته‌ی جداگانه‌ی `migros-mcp` را در npm دارد.

## برای ایجنت‌های هوش مصنوعی

```json
{
  "mcpServers": {
    "migros": {
      "command": "uvx",
      "args": ["migros-mcp==0.1.0"]
    }
  }
}
```

## ابزارها

| ابزار | توضیح |
|------|-------|
| `migros_search_products` | جست‌وجوی محصول — ‏`query` (مثلاً «süt»)، ‏`page`، ‏`sort`: ‏relevance / best_seller / discount / discount_amount / price_asc / price_desc |
| `migros_get_product` | جزئیات کامل یک محصول — ‏`product_id` (از نتایج جست‌وجو) |
| `migros_list_categories` | دسته‌بندی‌های اصلی فروشگاه (۱۱ مورد) |
| `migros_list_promotions` | محصولات تخفیف‌دار Money برای یک کلمه‌ی کلیدی، بیشترین تخفیف اول |
| `migros_price_stats` | آمار قیمت یک کلمه‌ی کلیدی (کمترین/میانه/بیشترین/میانگین، ارزان‌ترین و گران‌ترین) |

نکته‌ها:
- قیمت‌ها به لیر ترکیه (TRY) هستند؛ API قیمت را به کوروش (۱/۱۰۰ لیر) برمی‌گرداند.
- ‏`money_discount_pct` درصد تخفیف وفاداری Money است، نه تخفیف روی برچسب قیمت — قیمت قفسه همان قیمتی است که مشتری می‌پردازد.
- اولین نتیجه‌ی جست‌وجو معمولاً محصول اسپانسرشده است؛ بقیه طبق مرتب‌سازی درخواستی می‌آیند.
- داده: API عمومی JSON ‏`product-bff` میگروس — بدون کلید، بدون لاگین، فقط‌خواندنی.
- یافتن فروشگاه و بازه‌های تحویل نیازمند ورود است، پس در این سرور نیست.

## قوانین

غیررسمی و فقط‌خواندنی — بدون لاگین، بدون کلید، بدون نوشتن. تست‌ها: آفلاین با فیکسچر + تست زنده (۱۵/۱۵ سبز).
