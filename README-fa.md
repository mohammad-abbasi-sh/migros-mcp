# migros-mcp 🇹🇷

سرور MCP غیررسمی برای **میگروس** ترکیه (migros.com.tr)، بزرگ‌ترین زنجیره‌ی سوپرمارکتی ترکیه — جست‌وجوی زنده‌ی محصولات، قیمت‌ها، تخفیف‌های Money، دسته‌بندی‌ها و آمار قیمت. ابزارهای فقط‌خواندنی بدون لاگین کار می‌کنند. **اقدام‌های حساب کاربری** (سبد خرید + شروع پرداخت) اختیاری‌اند و از نشست مرورگر خودتان استفاده می‌کنند که فقط در پیکربندی MCP خودتان ذخیره می‌شود — ببینید [اقدام‌های حساب کاربری](#اقدامهای-حساب-کاربری).

> بخشی از «کارخانه‌ی MCP ترکیه». هیچ وابستگی به میگروس ندارد. این میگروس **ترکیه** است — نه میگروس سوئیس که بسته‌ی جداگانه‌ی `migros-mcp` را در npm دارد.

## برای ایجنت‌های هوش مصنوعی

```json
{
  "mcpServers": {
    "migros": {
      "command": "uvx",
      "args": ["migros-mcp==0.2.0"]
    }
  }
}
```

برای اقدام‌های حساب کاربری (سبد خرید + شروع پرداخت)، کوکی نشست
مرورگرتان را به پیکربندی اضافه کنید — ببینید
[اقدام‌های حساب کاربری](#اقدامهای-حساب-کاربری):

```json
{
  "mcpServers": {
    "migros": {
      "command": "uvx",
      "args": ["migros-mcp==0.2.0"],
      "env": {
        "MIGROS_SESSION": "YOUR_SESSION_COOKIE_HERE"
      }
    }
  }
}
```

## ابزارها

| ابزار | توضیح |
|------|-------|
| `migros_search_products` | جست‌وجوی محصول — ‏`query` (مثلاً «süt»)، ‏`page`، ‏`sort`: ‏relevance / best_seller / discount / discount_amount / price_asc / price_desc |
| `migros_get_product` | جزئیات کامل یک محصول — ‏`product_id` (از نتایج جست‌وجو) |
| `migros_list_categories` | دسته‌بندی‌های اصلی فروشگاه (۱۱ مورد) |
| `migros_list_promotions` | محصولات تخفیف‌دار Money برای یک کلمه‌ی کلیدی، بیشترین تخفیف اول |
| `migros_price_stats` | آمار قیمت یک کلمه‌ی کلیدی (کمترین/میانه/بیشترین/میانگین، ارزان‌ترین و گران‌ترین) |
| `migros_view_cart` | سبد خرید شما: اقلام (شناسه‌ی قلم، شناسه‌ی محصول، نام، تعداد، واحد، قیمت کل به لیر)، جمع‌ها و لینک سبد — نیازمند `MIGROS_SESSION` |
| `migros_add_to_cart` | افزودن محصول به سبد (`product_id`، ‏`quantity` ‏۱ تا ۹۹، منطق جایگزینی) — نیازمند نشست + ‏`confirm=true` |
| `migros_remove_from_cart` | حذف محصول از سبد (`product_id`) — نیازمند نشست + ‏`confirm=true` |
| `migros_update_cart_quantity` | تغییر تعداد یک قلم سبد (`product_id`، ‏`quantity` ‏۱ تا ۹۹) — نیازمند نشست + ‏`confirm=true` |
| `migros_create_order` | شروع پرداخت: سبد را بررسی می‌کند و لینک پرداخت (ödeme) را برمی‌گرداند — سفارشی ثبت نمی‌کند و هرگز پرداخت انجام نمی‌دهد — نیازمند `MIGROS_SESSION` |

نکته‌ها:
- قیمت‌ها به لیر ترکیه (TRY) هستند؛ API قیمت را به کوروش (۱/۱۰۰ لیر) برمی‌گرداند.
- ‏`money_discount_pct` درصد تخفیف وفاداری Money است، نه تخفیف روی برچسب قیمت — قیمت قفسه همان قیمتی است که مشتری می‌پردازد.
- اولین نتیجه‌ی جست‌وجو معمولاً محصول اسپانسرشده است؛ بقیه طبق مرتب‌سازی درخواستی می‌آیند.
- داده: API عمومی JSON ‏`product-bff` میگروس — بدون کلید، بدون لاگین، فقط‌خواندنی.
- تعداد اقلام سبد با **منطق جایگزینی** کار می‌کند: تنظیم تعداد یک محصول، مقدار آن را همان عدد می‌کند — روی مقدار موجود اضافه نمی‌شود. هر محصول یک سقف تعداد هم دارد؛ سرور تعداد بالاتر را رد می‌کند.
- یافتن فروشگاه و بازه‌های تحویل نیازمند ورود است، پس در این سرور نیست.

## اقدام‌های حساب کاربری

ابزارهای سبد خرید با **نشست مرورگر خودتان** کار می‌کنند — بدون رمز
عبور، بدون کلید API و بدون ساخت حساب در هیچ‌جا. نشست فقط در
پیکربندی MCP روی دستگاه خودتان می‌ماند و فقط به migros.com.tr
فرستاده می‌شود. سرور هرگز آن را لاگ نمی‌کند، چاپ نمی‌کند یا ذخیره
نمی‌کند و در هیچ خروجی ابزاری دیده نمی‌شود. هر تغییر سبد (افزودن /
حذف / تغییر تعداد) به ‏`confirm=true` هم نیاز دارد؛ وگرنه هیچ کاری
انجام نمی‌شود.

### راه‌اندازی (یک بار)

۱. در مرورگرتان (Chrome / Edge / Firefox) وارد
‏[migros.com.tr](https://www.migros.com.tr) شوید.
۲. ابزار توسعه‌دهنده را باز کنید (F12) → زبانه‌ی **Network** → صفحه را
تازه‌سازی کنید.
۳. روی هر درخواستی به ‏`migros.com.tr` کلیک کنید → ‏**Headers** →
سربرگ درخواست **Cookie** را پیدا کنید → مقدار کامل آن را کپی کنید.
(جایگزین: ابزار توسعه‌دهنده → ‏**Application** → ‏**Cookies** →
‏`https://www.migros.com.tr` — اما سربرگ Cookie در زبانه‌ی Network
مقدار کامل است؛ همان را کپی کنید.)
۴. آن را با نام ‏`MIGROS_SESSION` در پیکربندی MCP خودتان بچسبانید
(مثال بالا را ببینید) و سرور MCP را دوباره راه‌اندازی کنید.
۵. ‏`migros_view_cart` را امتحان کنید — باید سبد واقعی‌تان را نشان دهد.

### نکته‌ها

- نشست منقضی می‌شود: وقتی ابزاری «session expired» گزارش داد،
مراحل ۲ تا ۴ را برای کپی کوکی‌های تازه تکرار کنید. خروج از
migros.com.tr نشست را فوراً باطل می‌کند.
- **مقدار کوکی را هرگز به اشتراک نگذارید** — هر کسی که آن را داشته
باشد به حساب میگروس شما دسترسی کامل دارد (سبد، سفارش‌ها). آن را در
چت‌ها، issueها یا اسکرین‌شات‌ها نچسبانید.
- اقدام‌های حساب کاربری عمداً محدودند: سبد (مشاهده / افزودن / حذف /
تغییر تعداد) و شروع پرداخت (فقط لینک پرداخت را برمی‌گرداند). ثبت
سفارش، پرداخت، کوپن یا اقدام گروهی وجود ندارد.
‏`migros_create_order` هرگز سفارش ثبت نمی‌کند — آدرس، بازه‌ی تحویل و
پرداخت را خودتان در مرورگر کامل می‌کنید.
- ‏`store_id` / ‏`unit` به‌صورت خودکار از جزئیات عمومی محصول حل
می‌شوند؛ فقط برای رد کردن آن جست‌وجو آن‌ها را بدهید.
- نقاط پایانی سبد از کد عمومی فروشگاه میگروس مهندسی معکوس شده و تا
حد ممکن بدون حساب به‌صورت زنده بررسی شده‌اند (API سبد به درخواست‌های
بدون کوکی HTTP 400 خالی و API سفارش HTTP 401 برمی‌گرداند). شکل
پاسخ‌ها دفاعی تجزیه می‌شود — شکل ناشناخته یک یادداشت صریح
برمی‌گرداند و هرگز داده‌ی ساختگی تولید نمی‌کند.

## قوانین

غیررسمی — ابزارهای فقط‌خواندنی بدون لاگین و بدون کلید کار می‌کنند. ابزارهای سبد فقط با نشست خودتان کار می‌کنند و پرداخت انجام نمی‌دهند. تست‌ها: آفلاین با فیکسچر + تست زنده.
